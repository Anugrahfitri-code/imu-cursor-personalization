# M2.3 Clock Synchronization Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a dedicated UDP clock-synchronization subsystem on port 5006 that estimates an auditable affine mapping `t_PC = alpha * t_phone + beta` between Samsung Android monotonic time and PC monotonic time without modifying the frozen M2.2 IMU receiver on port 5005.

**Architecture:** The Android app gains a responder thread on UDP 5006, isolated from the existing sensor callback and UDP DATA path. The PC gains a `pc.clock_sync` package that formats/validates probes, executes startup/background/shutdown probe schedules, writes raw probe logs, selects time-distributed low-delay observations, performs a centered two-stage robust affine fit, and writes reproducible JSON/text summaries. Bench outputs stay under ignored `bench_data/M2_clock_sync`; Git contains only source, tests, design spec, and this plan.

**Tech Stack:** Android Java, `DatagramSocket`, `SystemClock.elapsedRealtimeNanos()`, Python 3.13 standard library (`socket`, `time`, `csv`, `json`, `statistics`, `dataclasses`, `argparse`, `pathlib`), pytest 9.x, existing Android Gradle/JUnit setup.

**Spec:** `docs/superpowers/specs/2026-09-05-m2.3-clock-synchronization-design.md`

## Global Constraints

- Port `5005` remains the frozen IMU DATA path and must not be modified for M2.3.
- Port `5006` is dedicated to clock-sync control traffic.
- PC is the probe initiator; Samsung is the responder.
- Android `t2_phone_ns` and `t3_phone_ns` use `SystemClock.elapsedRealtimeNanos()`.
- PC `t1_pc_ns` and `t4_pc_ns` use `time.monotonic_ns()`.
- Request format is exactly `SYNC_REQ,1,<seq>,<t1_pc_ns>`.
- Response format is exactly `SYNC_RESP,1,<seq>,<t1_pc_ns>,<t2_phone_ns>,<t3_phone_ns>`.
- Startup schedule: 30 probes at nominal 50 ms intervals.
- Background schedule: 1 probe every 2 s.
- Shutdown schedule: 30 probes at nominal 50 ms intervals.
- Background low-delay selection: one valid minimum-`delay_like_ns` probe per non-overlapping 10 s block.
- Main model is centered affine OLS followed by fixed residual-MAD screening and a final centered OLS refit.
- Freeze the robust cutoff as `MAD_MULTIPLIER = 6.0` applied to raw MAD around the median residual. This is deliberately conservative and may not be tuned per run.
- Hard response-rate gate: `>= 95%`.
- Broad skew sanity gate: `abs(skew_ppm) < 1000`.
- Timing-quality thresholds (e.g. residual P95) are not chosen until the 2/10/25-minute bench distribution is reviewed, and must be frozen before pilot participants.
- Bench runs: 2 min, 10 min, 25 min.
- Human-study active pointing target: `<= 10 min`; clock sync remains automatic/background.
- Clock-sync failure must not crash or block the sensor path.
- Runtime probe CSV/JSON/TXT must not be committed.
- Do not claim sensor-to-photon latency from M2.3.

```python
from __future__ import annotations

from dataclasses import dataclass


SYNC_PROTOCOL_VERSION = 1


@dataclass(frozen=True)
class SyncResponse:
    seq: int
    t1_pc_ns: int
    t2_phone_ns: int
    t3_phone_ns: int


def build_sync_request(
    seq: int,
    t1_pc_ns: int,
) -> str:
    if seq < 0:
        raise ValueError("seq must be >= 0")
    if t1_pc_ns < 0:
        raise ValueError("t1_pc_ns must be >= 0")

    return (
        f"SYNC_REQ,{SYNC_PROTOCOL_VERSION},"
        f"{seq},{t1_pc_ns}"
    )


def parse_sync_response(
    message: str,
    *,
    expected_seq: int,
    expected_t1_pc_ns: int,
) -> SyncResponse:
    parts = message.strip().split(",")

    if len(parts) != 6:
        raise ValueError(
            f"expected 6 fields, got {len(parts)}"
        )

    if parts[0] != "SYNC_RESP":
        raise ValueError(
            f"invalid message type: {parts[0]}"
        )

    try:
        version = int(parts[1])
        seq = int(parts[2])
        t1_pc_ns = int(parts[3])
        t2_phone_ns = int(parts[4])
        t3_phone_ns = int(parts[5])
    except ValueError as exc:
        raise ValueError(
            "numeric field parse error"
        ) from exc

    if version != SYNC_PROTOCOL_VERSION:
        raise ValueError(
            f"unsupported protocol version: {version}"
        )

    if seq != expected_seq:
        raise ValueError(
            f"sequence mismatch: expected "
            f"{expected_seq}, got {seq}"
        )

    if t1_pc_ns != expected_t1_pc_ns:
        raise ValueError(
            "t1 echo mismatch"
        )

    if t3_phone_ns < t2_phone_ns:
        raise ValueError(
            "t3 before t2"
        )

    return SyncResponse(
        seq=seq,
        t1_pc_ns=t1_pc_ns,
        t2_phone_ns=t2_phone_ns,
        t3_phone_ns=t3_phone_ns,
    )
```

```python
from __future__ import annotations

from dataclasses import dataclass
from math import isfinite
from statistics import median
from typing import Iterable


MAD_MULTIPLIER = 6.0
DEFAULT_BLOCK_NS = 10_000_000_000


@dataclass(frozen=True)
class ProbeObservation:
    session_id: str
    probe_phase: str
    probe_seq: int
    t1_pc_ns: int
    t2_phone_ns: int
    t3_phone_ns: int
    t4_pc_ns: int
    response_valid: bool
    invalid_reason: str = ""

    @property
    def pc_rtt_ns(self) -> int:
        return self.t4_pc_ns - self.t1_pc_ns

    @property
    def phone_processing_ns(self) -> int:
        return self.t3_phone_ns - self.t2_phone_ns

    @property
    def delay_like_ns(self) -> int:
        return self.pc_rtt_ns - self.phone_processing_ns

    @property
    def phone_mid_ns(self) -> int:
        return (
            self.t2_phone_ns + self.t3_phone_ns
        ) // 2

    @property
    def pc_mid_ns(self) -> int:
        return (
            self.t1_pc_ns + self.t4_pc_ns
        ) // 2


@dataclass(frozen=True)
class ClockModel:
    alpha: float
    beta_ns: float
    skew_ppm: float
    selected_probe_seqs: tuple[int, ...]
    inlier_probe_seqs: tuple[int, ...]
    residual_ns_by_seq: dict[int, float]

    def map_phone_to_pc_ns(
        self,
        phone_ns: int,
    ) -> float:
        return self.alpha * phone_ns + self.beta_ns


def percentile(
    values: Iterable[float],
    q: float,
) -> float:
    vals = sorted(float(v) for v in values)

    if not vals:
        raise ValueError("percentile requires values")
    if not 0.0 <= q <= 1.0:
        raise ValueError("q must be in [0, 1]")
    if len(vals) == 1:
        return vals[0]

    position = (len(vals) - 1) * q
    lower = int(position)
    upper = min(lower + 1, len(vals) - 1)
    fraction = position - lower

    return (
        vals[lower] * (1.0 - fraction)
        + vals[upper] * fraction
    )


def _valid_background(
    probes: Iterable[ProbeObservation],
) -> list[ProbeObservation]:
    return [
        p
        for p in probes
        if (
            p.response_valid
            and p.probe_phase == "background"
            and p.t4_pc_ns >= p.t1_pc_ns
            and p.t3_phone_ns >= p.t2_phone_ns
            and p.delay_like_ns >= 0
        )
    ]


def select_low_delay_background(
    probes: Iterable[ProbeObservation],
    *,
    block_ns: int = DEFAULT_BLOCK_NS,
) -> list[ProbeObservation]:
    if block_ns <= 0:
        raise ValueError("block_ns must be > 0")

    valid = sorted(
        _valid_background(probes),
        key=lambda p: p.pc_mid_ns,
    )

    if not valid:
        return []

    origin = valid[0].pc_mid_ns
    blocks: dict[int, list[ProbeObservation]] = {}

    for probe in valid:
        block_index = (
            probe.pc_mid_ns - origin
        ) // block_ns

        blocks.setdefault(
            int(block_index),
            [],
        ).append(probe)

    return [
        min(
            blocks[index],
            key=lambda p: (
                p.delay_like_ns,
                p.probe_seq,
            ),
        )
        for index in sorted(blocks)
    ]


def _fit_xy(
    xs: list[float],
    ys: list[float],
) -> tuple[float, float]:
    if len(xs) != len(ys):
        raise ValueError("x/y length mismatch")
    if len(xs) < 2:
        raise ValueError(
            "at least two observations required"
        )

    x0 = median(xs)
    y0 = median(ys)

    xc = [x - x0 for x in xs]
    yc = [y - y0 for y in ys]

    denom = sum(x * x for x in xc)

    if denom == 0:
        raise ValueError(
            "phone timestamps have zero spread"
        )

    alpha = sum(
        x * y
        for x, y in zip(xc, yc)
    ) / denom

    intercept_centered = (
        sum(
            y - alpha * x
            for x, y in zip(xc, yc)
        )
        / len(xs)
    )

    beta = (
        y0
        + intercept_centered
        - alpha * x0
    )

    if not isfinite(alpha) or not isfinite(beta):
        raise ValueError("non-finite affine fit")

    return alpha, beta


def _residuals(
    probes: list[ProbeObservation],
    alpha: float,
    beta: float,
) -> dict[int, float]:
    return {
        p.probe_seq: (
            float(p.pc_mid_ns)
            - (
                alpha * float(p.phone_mid_ns)
                + beta
            )
        )
        for p in probes
    }


def fit_robust_clock_model(
    probes: Iterable[ProbeObservation],
    *,
    mad_multiplier: float = MAD_MULTIPLIER,
) -> ClockModel:
    selected = select_low_delay_background(
        probes
    )

    if len(selected) < 2:
        raise ValueError(
            "not enough selected background probes"
        )

    xs = [float(p.phone_mid_ns) for p in selected]
    ys = [float(p.pc_mid_ns) for p in selected]

    alpha0, beta0 = _fit_xy(xs, ys)
    residual0 = _residuals(
        selected,
        alpha0,
        beta0,
    )

    residual_values = list(residual0.values())
    center = median(residual_values)
    deviations = [
        abs(value - center)
        for value in residual_values
    ]
    mad = median(deviations)

    if mad == 0:
        inliers = [
            p
            for p in selected
            if residual0[p.probe_seq] == center
        ]
        if len(inliers) < 2:
            inliers = selected
    else:
        cutoff = mad_multiplier * mad
        inliers = [
            p
            for p in selected
            if abs(
                residual0[p.probe_seq] - center
            ) <= cutoff
        ]

    if len(inliers) < 2:
        raise ValueError(
            "robust screening left too few inliers"
        )

    alpha, beta = _fit_xy(
        [
            float(p.phone_mid_ns)
            for p in inliers
        ],
        [
            float(p.pc_mid_ns)
            for p in inliers
        ],
    )

    residual = _residuals(
        inliers,
        alpha,
        beta,
    )

    return ClockModel(
        alpha=alpha,
        beta_ns=beta,
        skew_ppm=(alpha - 1.0) * 1_000_000.0,
        selected_probe_seqs=tuple(
            p.probe_seq for p in selected
        ),
        inlier_probe_seqs=tuple(
            p.probe_seq for p in inliers
        ),
        residual_ns_by_seq=residual,
    )


def fit_half_diagnostics(
    probes: Iterable[ProbeObservation],
) -> tuple[ClockModel, ClockModel]:
    valid = sorted(
        _valid_background(probes),
        key=lambda p: p.pc_mid_ns,
    )

    if len(valid) < 4:
        raise ValueError(
            "at least four valid background "
            "probes required"
        )

    midpoint = len(valid) // 2

    first = fit_robust_clock_model(
        valid[:midpoint]
    )
    second = fit_robust_clock_model(
        valid[midpoint:]
    )

    return first, second
```

PROBE_TIMEOUT_S = 0.25

BURST_INTERVAL_S = 0.05
BACKGROUND_INTERVAL_S = 2.0


@dataclass(frozen=True)
class ScheduledProbe:
    phase: str
    target_offset_s: float


@dataclass
class ProbeResult:
    session_id: str
    probe_phase: str
    probe_seq: int
    t1_pc_ns: int
    t2_phone_ns: int | None
    t3_phone_ns: int | None
    t4_pc_ns: int
    response_valid: bool
    invalid_reason: str
    selected_low_delay: bool = False
    robust_inlier: bool = False
    model_residual_ns: float | None = None

    @classmethod
    def timeout(
        cls,
        *,
        session_id: str,
        probe_phase: str,
        probe_seq: int,
        t1_pc_ns: int,
        t4_pc_ns: int,
    ) -> "ProbeResult":
        return cls(
            session_id=session_id,
            probe_phase=probe_phase,
            probe_seq=probe_seq,
            t1_pc_ns=t1_pc_ns,
            t2_phone_ns=None,
            t3_phone_ns=None,
            t4_pc_ns=t4_pc_ns,
            response_valid=False,
            invalid_reason="timeout",
        )

    @property
    def pc_rtt_ns(self) -> int | None:
        if not self.response_valid:
            return None
        return self.t4_pc_ns - self.t1_pc_ns

    @property
    def phone_processing_ns(self) -> int | None:
        if (
            not self.response_valid
            or self.t2_phone_ns is None
            or self.t3_phone_ns is None
        ):
            return None
        return self.t3_phone_ns - self.t2_phone_ns

    @property
    def delay_like_ns(self) -> int | None:
        if (
            self.pc_rtt_ns is None
            or self.phone_processing_ns is None
        ):
            return None
        return (
            self.pc_rtt_ns
            - self.phone_processing_ns
        )

    @property
    def phone_mid_ns(self) -> int | None:
        if (
            self.t2_phone_ns is None
            or self.t3_phone_ns is None
        ):
            return None
        return (
            self.t2_phone_ns
            + self.t3_phone_ns
        ) // 2

    @property
    def pc_mid_ns(self) -> int:
        return (
            self.t1_pc_ns
            + self.t4_pc_ns
        ) // 2


def build_probe_schedule(
    *,
    background_duration_s: float,
) -> list[ScheduledProbe]:
    if background_duration_s < 0:
        raise ValueError(
            "background_duration_s must be >= 0"
        )

    schedule: list[ScheduledProbe] = []

    for index in range(BURST_COUNT):
        schedule.append(
            ScheduledProbe(
                phase="startup",
                target_offset_s=(
                    index * BURST_INTERVAL_S
                ),
            )
        )

    background_start = (
        BURST_COUNT * BURST_INTERVAL_S
    )

    background_count = int(
        background_duration_s
        // BACKGROUND_INTERVAL_S
    )

    for index in range(background_count):
        schedule.append(
            ScheduledProbe(
                phase="background",
                target_offset_s=(
                    background_start
                    + index * BACKGROUND_INTERVAL_S
                ),
            )
        )

    shutdown_start = (
        background_start
        + background_duration_s
    )

    for index in range(BURST_COUNT):
        schedule.append(
            ScheduledProbe(
                phase="shutdown",
                target_offset_s=(
                    shutdown_start
                    + index * BURST_INTERVAL_S
                ),
            )
        )

    return schedule


def execute_probe(
    sock: socket.socket,
    *,
    phone_ip: str,
    session_id: str,
    phase: str,
    seq: int,
) -> ProbeResult:
    t1_pc_ns = time.monotonic_ns()
    request = build_sync_request(
        seq,
        t1_pc_ns,
    ).encode("utf-8")

    sock.sendto(
        request,
        (phone_ip, SYNC_PORT),
    )

    deadline = (
        time.monotonic()
        + PROBE_TIMEOUT_S
    )

    while True:
        remaining = (
            deadline - time.monotonic()
        )

        if remaining <= 0:
            return ProbeResult.timeout(
                session_id=session_id,
                probe_phase=phase,
                probe_seq=seq,
                t1_pc_ns=t1_pc_ns,
                t4_pc_ns=time.monotonic_ns(),
            )

        sock.settimeout(remaining)

        try:
            payload, _addr = sock.recvfrom(4096)
        except socket.timeout:
            return ProbeResult.timeout(
                session_id=session_id,
                probe_phase=phase,
                probe_seq=seq,
                t1_pc_ns=t1_pc_ns,
                t4_pc_ns=time.monotonic_ns(),
            )

        t4_pc_ns = time.monotonic_ns()

        try:
            response = parse_sync_response(
                payload.decode("utf-8"),
                expected_seq=seq,
                expected_t1_pc_ns=t1_pc_ns,
            )
        except (
            UnicodeDecodeError,
            ValueError,
        ):
            # Ignore stale/malformed/unmatched responses
            # until this probe's deadline.
            continue

        result = ProbeResult(
            session_id=session_id,
            probe_phase=phase,
            probe_seq=seq,
            t1_pc_ns=t1_pc_ns,
            t2_phone_ns=(
                response.t2_phone_ns
            ),
            t3_phone_ns=(
                response.t3_phone_ns
            ),
            t4_pc_ns=t4_pc_ns,
            response_valid=True,
            invalid_reason="",
        )

        if (
            result.delay_like_ns is None
            or result.delay_like_ns < 0
        ):
            result.response_valid = False
            result.invalid_reason = (
                "negative_delay"
            )

        return result

    *,
    phone_ip: str,
    session_id: str,
    background_duration_s: float,
    output_root: Path,

        background_duration_s=(

        )
    )

    rows: list[ProbeResult] = []

    session_dir = (
        output_root / session_id
    )
    csv_path = (
        session_dir / "sync_probes.csv"
    )

    sock = socket.socket(
        socket.AF_INET,
        socket.SOCK_DGRAM,
    )

    start = time.monotonic()

    try:
        for seq, item in enumerate(
            schedule,
            start=1,
        ):
            target = (
                start + item.target_offset_s
            )
            sleep_s = target - time.monotonic()

            if sleep_s > 0:
                time.sleep(sleep_s)

            result = execute_probe(
                sock,
                phone_ip=phone_ip,
                session_id=session_id,
                phase=item.phase,
                seq=seq,
            )
            rows.append(result)

            if seq % 10 == 0:
                valid = sum(
                    r.response_valid
                    for r in rows
                )
                print(
                    f"probes={seq} "
                    f"valid={valid} "
                    f"invalid={seq-valid}"
                )
    finally:
        sock.close()
        write_probe_csv(
            csv_path,
            rows,
        )

    return csv_path

```java
package com.imucursor.research;

public final class ClockSyncProtocol {

    public static final int VERSION = 1;

    private ClockSyncProtocol() {
    }

    public static final class Request {
        public final long seq;
        public final long t1PcNs;

        public Request(
                long seq,
                long t1PcNs) {
            this.seq = seq;
            this.t1PcNs = t1PcNs;
        }
    }

    public static Request parseRequest(
            String message) {

        String[] parts =
                message.trim().split(",");

        if (parts.length != 4) {
            throw new IllegalArgumentException(
                    "Expected 4 fields"
            );
        }

        if (!"SYNC_REQ".equals(parts[0])) {
            throw new IllegalArgumentException(
                    "Invalid message type"
            );
        }

        int version;
        long seq;
        long t1PcNs;

        try {
            version =
                    Integer.parseInt(parts[1]);
            seq =
                    Long.parseLong(parts[2]);
            t1PcNs =
                    Long.parseLong(parts[3]);
        } catch (NumberFormatException e) {
            throw new IllegalArgumentException(
                    "Numeric parse error",
                    e
            );
        }

        if (version != VERSION) {
            throw new IllegalArgumentException(
                    "Unsupported protocol version"
            );
        }

        if (seq < 0 || t1PcNs < 0) {
            throw new IllegalArgumentException(
                    "Negative seq/timestamp"
            );
        }

        return new Request(
                seq,
                t1PcNs
        );
    }

    public static String buildResponse(
            Request request,
            long t2PhoneNs,
            long t3PhoneNs) {

        if (t3PhoneNs < t2PhoneNs) {
            throw new IllegalArgumentException(
                    "t3 before t2"
            );
        }

        return "SYNC_RESP,"
                + VERSION
                + ","
                + request.seq
                + ","
                + request.t1PcNs
                + ","
                + t2PhoneNs
                + ","
                + t3PhoneNs;
    }
}
```

```java
package com.imucursor.research;

import android.os.SystemClock;

import java.io.IOException;
import java.net.DatagramPacket;
import java.net.DatagramSocket;
import java.net.SocketException;
import java.net.SocketTimeoutException;
import java.nio.charset.StandardCharsets;
import java.util.concurrent.atomic.AtomicLong;

public final class ClockSyncServer {

    public static final int DEFAULT_PORT = 5006;
    private static final int BUFFER_SIZE = 1024;
    private static final int SOCKET_TIMEOUT_MS = 250;

    private final int port;
    private final AtomicLong validRequestCount =
            new AtomicLong();
    private final AtomicLong malformedRequestCount =
            new AtomicLong();
    private final AtomicLong sendErrorCount =
            new AtomicLong();

    private volatile boolean running;
    private Thread thread;
    private DatagramSocket socket;

    public ClockSyncServer(int port) {
        this.port = port;
    }

    public synchronized void start() {
        if (running) {
            return;
        }

        running = true;

        thread = new Thread(
                this::runLoop,
                "ClockSyncServer"
        );
        thread.start();
    }

    public synchronized void stop() {
        running = false;

        DatagramSocket current = socket;
        if (current != null) {
            current.close();
        }

        Thread currentThread = thread;
        if (currentThread != null) {
            try {
                currentThread.join(1500);
            } catch (InterruptedException e) {
                Thread.currentThread()
                        .interrupt();
            }
        }

        thread = null;
        socket = null;
    }

    private void runLoop() {
        try (DatagramSocket localSocket =
                     new DatagramSocket(port)) {

            socket = localSocket;
            localSocket.setSoTimeout(
                    SOCKET_TIMEOUT_MS
            );

            byte[] buffer =
                    new byte[BUFFER_SIZE];

            while (running) {
                DatagramPacket requestPacket =
                        new DatagramPacket(
                                buffer,
                                buffer.length
                        );

                try {
                    localSocket.receive(
                            requestPacket
                    );
                } catch (
                        SocketTimeoutException e) {
                    continue;
                } catch (SocketException e) {
                    if (!running) {
                        break;
                    }
                    throw e;
                }

                long t2PhoneNs =
                        SystemClock
                                .elapsedRealtimeNanos();

                String requestText =
                        new String(
                                requestPacket.getData(),
                                requestPacket.getOffset(),
                                requestPacket.getLength(),
                                StandardCharsets.UTF_8
                        );

                final ClockSyncProtocol.Request
                        request;

                try {
                    request =
                            ClockSyncProtocol
                                    .parseRequest(
                                            requestText
                                    );
                } catch (
                        IllegalArgumentException e) {
                    malformedRequestCount
                            .incrementAndGet();
                    continue;
                }

                long t3PhoneNs =
                        SystemClock
                                .elapsedRealtimeNanos();

                String responseText =
                        ClockSyncProtocol
                                .buildResponse(
                                        request,
                                        t2PhoneNs,
                                        t3PhoneNs
                                );

                byte[] responseBytes =
                        responseText.getBytes(
                                StandardCharsets.UTF_8
                        );

                DatagramPacket responsePacket =
                        new DatagramPacket(
                                responseBytes,
                                responseBytes.length,
                                requestPacket
                                        .getAddress(),
                                requestPacket
                                        .getPort()
                        );

                try {
                    localSocket.send(
                            responsePacket
                    );
                    validRequestCount
                            .incrementAndGet();
                } catch (IOException e) {
                    sendErrorCount
                            .incrementAndGet();
                }
            }

        } catch (IOException e) {
            if (running) {
                sendErrorCount
                        .incrementAndGet();
            }
        } finally {
            running = false;
        }
    }

    public long getValidRequestCount() {
        return validRequestCount.get();
    }

    public long getMalformedRequestCount() {
        return malformedRequestCount.get();
    }

    public long getSendErrorCount() {
        return sendErrorCount.get();
    }
}
```

Note: `t3PhoneNs` is taken after request parsing and immediately before response construction/send. Do not add logging or disk I/O between `t2` and `t3`.
